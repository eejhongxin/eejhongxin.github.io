## IMU测试步骤

### 给CPU施加压力

```
nohup taskset -c 0-7 stress-ng --cpu 8 --cpu-load 80 > /userdata/stress80.log 2>&1 < /dev/null &
```

可以通过以下命令来查看施加结果

```
ps
top
```

## PWM测试步骤

压力命令

```
nohup taskset -c 0-7 stress-ng --cpu 8 --cpu-load 80 > /userdata/stress80.log 2>&1 < /dev/null &
```

运行脚本

```
/userdata/pwm_test -m loopback -p 1000000000 -d 500000000 -n 10
```

后台运行

```
nohup /userdata/pwm_period_test 13000 > /userdata/pwm-3h.csv 2> /userdata/pwm-3h.log < /dev/null &
```

实时观看

```
tail -f /userdata/pwm-3h.csv
```
