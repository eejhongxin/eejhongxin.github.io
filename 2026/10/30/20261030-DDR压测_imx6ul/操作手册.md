# i.MX6UL P5 DDR 压测操作手册

本手册对应当前归档的统一完整包 `ddr-p5-full.tar.gz`。安装前先阅读 [版本说明](<01_安装包/版本说明.md>)；完整参数及环境要求见 [统一入口说明](<02_脚本/新统一入口/README.md>)。

## 准备挂载与安装目录

在板子 root 串口终端执行：

```sh
if ! grep -q ' /mnt ' /proc/mounts; then
    mkdir -p /mnt
    mount -t vfat -o rw /dev/mmcblk1p7 /mnt
fi
cat /proc/mounts | grep ' /mnt '
df -h /mnt
mkdir -p /mnt/ddr_work
cd /mnt/ddr_work
```

确认输出为 `/dev/mmcblk1p7 /mnt vfat rw,...` 后，再上传 [统一完整包](<01_安装包/ddr-p5-full.tar.gz>)。已有测试或喂狗正在使用同路径文件时，先保留现场，等测试结束后再安排更新。

## 解压与运行

```sh
tar -xzf ddr-p5-full.tar.gz
sh ddr_p5/run.sh 6
```

入口准备运行环境、归档旧日志并后台启动 6 轮测试。这里仅整理现有操作说明，本次没有重新部署或运行板端测试。

## 查看状态与结果

```sh
sh /mnt/ddr_work/ddr_p5/run.sh status
sh /mnt/ddr_work/ddr_p5/run.sh progress
tail -f /mnt/ddr_work/ddr_all_test/console.log
```

按每轮 SAT 的 PASS、memtester 的 Done 与各项结果、BIN/TAR Success 以及内核 OOM 日志共同判断结果，不能只凭进程退出码认定全部通过。

普通运行不安装开机自启；需要自启时，按 [统一入口说明](<02_脚本/新统一入口/README.md>) 在当前测试结束后单独配置。

已有数据和检查结论见 [测试数据](<03_测试数据/README.md>)、[整理核对结果](<04_检查与分析/整理核对结果.md>) 及 [任务总览](<README.md>)。
